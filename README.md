# Habit Tracker

Отдельный учебный проект для демонстрации Task Manager и GitHub App. Начальная библиотека и консольный пример: привычки и ежедневные отметки. Веб-интерфейс, сохранение и статистика добавляются отдельными задачами.

## Запуск

Нужен Node.js 24, внешних зависимостей нет.

```bash
npm start
npm test
```

Данные примера хранятся в памяти и не сохраняются между запусками.

## Задачи для Task Manager

- Добавить удаление привычки с тестами.
- Реализовать подсчёт серии выполнений.
- Сохранять данные в локальный JSON.
- Добавить веб-интерфейс ежедневных отметок.

Исходники Task Manager находятся в отдельном репозитории. Создание ветки для задачи само по себе не реализует её код.
